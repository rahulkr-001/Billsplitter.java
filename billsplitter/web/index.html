About Smart Bill Splitter

Project Overview

Smart Bill Splitter is a lightweight expense-sharing application designed to simplify group bill calculations and shared expense management. It supports equal and tax-inclusive bill splitting, dynamic participant management, individual contribution breakdowns, digital receipt generation, and persistent calculation history.

Built with Java and modern web technologies, the application provides a responsive browser-based dashboard powered by an embedded Java HTTP server, alongside a fully functional command-line interface.

Application Workflow

  • 1. Enter Bill Details: Provide the total expense amount and an optional description.
  • 2. Add Participants: Dynamically add or remove members with input validation.
  • 3. Configure Tax: Apply GST or service tax when applicable.
  • 4. Calculate Shares: Process the total expense and determine individual contributions.
  • 5. Generate Receipt: Create and save a formatted expense breakdown.
  • 6. Manage History: Review previous calculations and reload saved bills.

Java Concepts & Implementation

  • Classes and Objects: Organizing application functionality into reusable components.
  • Encapsulation: Managing application data through controlled access.
  • Inheritance: Sharing functionality between related bill classes.
  • Abstraction: Defining common behavior through the abstract Bill class.
  • Interfaces: Establishing common functionality through the Exportable interface.
  • Polymorphism: Supporting different bill calculation implementations.
  • Arrays & StringBuffer: Managing participant information and formatting receipts.
  • Exception Handling: Handling invalid inputs using custom exceptions.
  • Multithreading: Executing background reminder tasks.
  • File Handling & Synchronization: Managing persistent records and concurrent file operations.

Technology Stack

  • Java (JDK 11+): Core application logic and backend processing.
  • Java HTTP Server: Embedded server using com.sun.net.httpserver.HttpServer.
  • HTML5: Dashboard structure and interface elements.
  • CSS3: Responsive layouts, styling, and animations.
  • Vanilla JavaScript: Dynamic interactions and frontend logic.
  • JSON: Communication between the frontend and backend.
  • Java I/O: Local receipt and expense history storage.

Terminal & CLI Execution

The application also supports an interactive command-line interface without requiring the web dashboard.

java billsplitter.Main --cli

Alternatively, launch the default application and select option 2 from the console menu to enter CLI mode.

Core Project Components

  • Bill.java: Abstract bill model with EqualBill and TaxedBill implementations.
  • Exportable.java: Interface defining receipt export functionality.
  • InvalidBillException.java: Custom exception for bill validation.
  • Main.java: Application entry point and CLI/Web launch management.
  • WebServer.java: Embedded HTTP server and API request handling.
  • ReceiptManager.java: Receipt generation and file management.
  • BillHistoryManager.java: Persistent calculation history management.
  • PaymentReminderThread.java: Background payment reminder processing.
  • SimpleJson.java: Lightweight JSON parsing and serialization.

Local Data Storage

  • split_receipt.txt: Stores generated bill receipts.
  • bill_history.txt: Maintains previous bill calculations.
